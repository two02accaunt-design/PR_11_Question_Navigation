# Практична робота — Навігація між питаннями

## Реалізовано
- Якщо `numberQuestion === 0`, кнопка `Prev` приховується.
- Якщо `numberQuestion > 0`, кнопка `Prev` відображається.
- Якщо `numberQuestion === questions.length - 1`, кнопка `Next` приховується.
- Після переходу між питаннями видимість кнопок оновлюється.

## Запуск
Відкрийте `index.html` у браузері або через Live Server у Visual Studio Code.
